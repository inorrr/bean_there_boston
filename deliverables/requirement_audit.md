# Requirement Audit

## Site Requirements

| Requirement | Status | Where It Is Covered |
| --- | --- | --- |
| Clear statement of the problem and intended user | Complete | Overview screen and README describe cafe neighborhood exploration for small-business/student users. |
| Explanation of how data was collected | Complete | Data and Methods section, README, scripts, and source manifest. |
| At least three useful charts, maps, tables, or indicators | Complete | Opportunity-score map, point layers, Neighborhood Signal Mix chart, Opportunity Gap scatterplot, ranking table, overview indicators. |
| Filters or comparison controls | Complete | Weight sliders, score presets, point-layer toggles, selected-neighborhood details, neighborhood comparison selector, table search, and multi-column table sorting. |
| Summary of important findings | Complete | Comparison views, ranking table, presentation, methodology note, and reflection. |
| Two or more practical recommendations supported by data | Complete | Presentation recommendations, methodology note, reflection, and ranking/comparison views. |
| Sources, dates, units, and definitions | Complete | Sources section, source manifest, README, and methodology note. |
| Missing data, bias, uncertainty, and limitations | Complete | Methods section, methodology note, and reflection. |
| Works on computers and phones | Complete | Desktop uses overlay map panels; mobile stacks score controls, map, and selected-neighborhood details as normal sections. |
| No sensitive personal data | Complete | Only public aggregate/administrative datasets are used; no names, contact details, medical data, or precise personal locations are collected. |
